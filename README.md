# Проклятое подземелье — прототип

Рогалик-кликер с видом от первого лица: герой поднимается из темницы проклятого подземелья,
сражается с девушками-монстрами одной кнопкой и забирает побеждённых в свой отряд.

Чистый JavaScript + Canvas 2D, без фреймворков и сборки. Вертикальный экран, ПК и мобильный браузер.

## Как запустить

**На ПК:** откройте `index.html` двойным щелчком.

**На телефоне:** запустите маленький сервер на ПК и откройте игру с телефона в той же Wi‑Fi сети:

```
python -m http.server 8000
```

Затем на телефоне: `http://<IP-адрес-ПК>:8000`.

## Языки

Русский и английский. Язык выбирается по языку браузера, переключатель «🌐 English / 🌐 Русский» — внизу главного меню.
Для проверки можно открыть игру с параметром `index.html?lang=en` или `?lang=ru`.

## Управление в бою

| Действие | Что делает |
| --- | --- |
| Тап | Удар. Тратит выносливость; при спаме — одышка, удары почти не наносят урона |
| Пауза | Через 0,6 с без ударов копится заряд, до ×2,5 к 2 с |
| Нажатие в круг удара | Во время замаха: зелёное кольцо — парирование; палец в круге в момент удара — блок |
| Росчерк по противнице | Рассечение, использует заряд |
| Росчерк через 2+ сферы | Сферы исчезают, противница теряет выносливость |
| Росчерк поперёк огонька или лианы | Убрать помеху босса |
| Тап по золотой точке | Крит |
| Без брони: круг на противнице | Захват (печать тратится только при успехе) |

Броня ломается, когда выносливость противницы ниже 30% и удар заряжен (×1.8+) или это росчерк.
Если здоровье кончится раньше, чем вся броня, — противница сбежит, захватить её нельзя.

Без брони противница получает двойной урон и уже не сдаётся: бой идёт, пока у неё есть здоровье или пока её не поймают.
Рядовые без брони атакуют вдвое реже. Захват — круг, начерченный на ней:
шанс = 70% × (1 − доля выносливости), то есть 70% при пустой выносливости и 0% при полной.
Неудача — противница получает урон росчерка, печать остаётся. Числа — `broken` в `js/data.js`.

## Противницы

| Героиня | Роль | Особенность |
| --- | --- | --- |
| Крольчиха | Обычная | Частые слабые удары, электрические сферы (шок) |
| Лиса-жрица | Обычная | Долгий замах, огненные и ледяные сферы |
| Волчица | Мини-босс | Серии до трёх ударов, ярость после поломки брони |
| Нэкомата | Босс этажа | Три фазы, призрачные огоньки лишают защиты, сферы холодного пламени |

У каждой — 2 части брони и пока один спрайт. Спрайтов может быть меньше, чем частей брони:
стадии сменяются по доле сломанной брони.

## Уровень

«Этаж 1 — Подъём из темницы»: комнаты от первого лица с дверями и значками над ними, бои, мини-босс,
привал, события, сундук, босс. Опыт и уровни героя, реликвии, улучшения, печати захвата.
Пойманные спутницы сохраняются в браузере навсегда.

Этаж каждый раз генерируется заново — это граф как в Slay the Spire, нарисованный планом подземелья:
комнаты стоят поясами от темницы к залу босса, двери — на общих стенах соседних комнат.
Путь героя — 10 комнат (темница и ещё 9), 11-я — босс. Из комнаты 1–3 двери, тупиков нет, назад пути нет.
Первая комната после темницы — бой, последняя перед боссом — привал; привал, элита и сокровище
не идут два раза подряд; на этаже есть хотя бы одна элита.

План внизу экрана: видны значки пройденных комнат и тех, куда ведут двери из текущей
(дальность разведки — `floor.scout`, позже её смогут увеличивать спутницы), остальное скрыто туманом.
Нажатие на светящуюся комнату — переход туда, нажатие на план — крупный план этажа.
Настройки этажа — `floor` в `js/data.js`.

## Редактор противниц

Кнопка «Редактор противниц» в меню: загрузить спрайт или лист стадий (фон убирается сам),
задать характеристики, число частей брони, место на этаже, проверить в тестовом бою.
Свои героини хранятся только в браузере (IndexedDB) и в репозиторий не попадают.
Экспорт: набор `.json` для переноса или `.zip` со спрайтами и записью для `js/data.js`.

## Локальные спрайты (папка `packs`)

Папка `packs/` исключена из git. Положите туда `pack.js` (образец — `packs/pack.example.js`),
и игра на вашем компьютере заменит спрайты и числа героинь своими, не меняя репозиторий.
Подробнее — `packs/README.md`.

## Файлы

```
index.html                  страница и интерфейс (меню, итоги, панели, редактор)
js/data.js                  баланс: герой, противницы, стихии, реликвии, улучшения, план этажа
js/game.js                  движок, бой, уровень
js/editor.js                редактор противниц
assets/<id>/stageN.png      спрайты
tools/prepare_sprites.py    подготовка спрайтов из листа (Python, необязательно)
packs/                      локальные спрайты, не хранятся в git
CLAUDE.md                   карта проекта для ИИ-помощника
```

## Как добавить героиню в репозиторий

1. Через редактор: «Экспорт в проект (.zip)» → скопировать папку `assets/<id>` и вставить запись в `js/data.js`.
2. Или вручную: `python tools/prepare_sprites.py картинка.png assets/<id> --stages 1`
   (нужны `pip install pillow numpy scipy`; для белой одежды на белом фоне добавьте `--no-holes`),
   затем запись в `js/data.js` по образцу.
