# Локальные спрайты

Всё в этой папке, кроме этого файла и `pack.example.js`, исключено из git (см. `.gitignore`).
Здесь можно держать свои спрайты и настройки, которые не должны попадать в репозиторий.

## Просто картинки — без настроек

Положите стадии в папку с id героини:

```
packs/
  moth/
    stage2.png     броня сломана один раз
    stage3.png     брони нет
```

Id — ключ героини в `js/data.js`: `bunny`, `miko`, `moth`, `wolf`, `nekomata`.
Игра при запуске сама ищет `packs/<id>/stage1.png`, `stage2.png`, … (всего стадий — число частей брони + 1).
Чего в папке нет, берётся из `assets/` — обычно там лежит только `stage1.png`, поэтому достаточно
положить `stage2.png` и `stage3.png`. Работает и при запуске двойным щелчком.
Найденные стадии игра пишет в консоль браузера (F12): `packs/moth: 3 stages`.

Требования к картинкам: PNG с прозрачным фоном, фигура стоит внизу по центру холста. Лист стадий удобно
разрезать в «Редакторе противниц» — он же уберёт фон и пустые поля.

Игра сама подгоняет стадии при загрузке:
- стадия другого разрешения (например, вдвое крупнее) масштабируется под размер `stage1.png`;
- стадия других пропорций вписывается в холст первой стадии по низу и центру (ноги остаются на месте);
- картинки больше 2048 px по большей стороне уменьшаются (экономия памяти).
Что именно подогнано, игра пишет в консоль (F12): `sprites moth: stage 2: 1330×1792 → 665×896`.
Лучше всего, если все стадии нарисованы на одном холсте: тогда ничего не сдвигается.

## pack.js — когда нужно больше

`packs/pack.js` позволяет поменять любые числа героини, число частей брони, задать спрайты с другими
путями и добавить совсем новую героиню (образец — `pack.example.js`, скопируйте его в `pack.js`).
Если в `pack.js` у героини задано `sprites`, папка `packs/<id>/` для неё не используется.

Портреты отряда вырезаются вокруг головы. Если игра открыта двойным щелчком (file://), Chrome не даёт
найти голову по силуэту — тогда задайте её вручную: `portrait: { x: 0.48, y: 0.11 }` (доли ширины и высоты спрайта).
