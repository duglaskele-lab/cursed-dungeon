# Локальные спрайты

Всё в этой папке, кроме этого файла и `pack.example.js`, исключено из git (см. `.gitignore`).
Здесь можно держать свои спрайты и настройки, которые не должны попадать в репозиторий.

## Как подключить

1. Скопируйте `pack.example.js` в `pack.js` в этой же папке.
2. Положите свои картинки рядом, например `packs/x/miko/stage1.png … stage3.png`.
3. Укажите их в `pack.js`. Игра подхватит файл автоматически; если `pack.js` нет — работает как обычно.

Можно заменить спрайты, число частей брони и любые числа героини, а также добавить новую героиню.
Путь к картинкам указывается от корня игры (`packs/x/...`).

Портреты отряда вырезаются вокруг головы. Если игра открыта двойным щелчком (file://), Chrome не даёт
найти голову по силуэту — тогда задайте её вручную: `portrait: { x: 0.48, y: 0.11 }` (доли ширины и высоты спрайта).
